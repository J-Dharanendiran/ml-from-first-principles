# The Tale of Two Regressions: From One Class to Many 🎭

Once upon a pipeline, there lived a humble algorithm called **Binary Logistic Regression**. It had one job — decide between two doors: *Class 0* or *Class 1*. Then one day, the problem grew up. Three classes. Five classes. A whole family of possibilities. Logistic Regression couldn't handle that alone, so it evolved into something bigger: **Softmax Regression**.

Here's the twist though — *Softmax Regression isn't a stranger*. It's the same pipeline, just stretched to fit a bigger world. Let's walk through the journey, stage by stage.

> "You're not learning an unrelated algorithm. You're taking the logistic-regression pipeline you already understand and extending each stage from 'two classes' to 'many classes.'"

---

## 🎬 Scene 1: The Question Each Model Asks

Logistic Regression lives in a world of two outcomes:

```text
y ∈ {0, 1}
```

Picture a placement dataset:

```text
0 → Not Placed
1 → Placed
```

Its whole existence revolves around one question:

> **"Is this Class 1 or Class 0?"**

Softmax Regression, on the other hand, lives in a world with more doors:

```text
y ∈ {0, 1, 2, ..., K-1}
```

```text
0 → Placed
1 → Not Placed
2 → Opt-out
```

Its question is broader:

> **"Which class among *all* of these?"**

And *that single shift in the question* — from binary to multiclass — is the seed from which every other difference grows.

---

## 🎬 Scene 2: The Input Doesn't Change

Here's a comforting truth: **both models start their story identically**. They both look at the same features.

Say we have:

```text
X = [CGPA, IQ]
x₁ = 7.5
x₂ = 85
```

```text
Features
   ↓
CGPA, IQ
```

Nothing dramatic happens yet. The plot twist comes *after* the input is received.

---

## 🎬 Scene 3: One Score vs. Many Scores

This is where the paths genuinely fork.

**Logistic Regression** calculates just *one* linear score:

$$z = w_1x_1 + w_2x_2 + b$$

For example, `z = 2.3`. One input, one number, one verdict brewing.

**Softmax Regression** instead calculates a score *for every class it's choosing between*. For 3 classes:

$$z_1 = w_{11}x_1 + w_{21}x_2 + b_1$$
$$z_2 = w_{12}x_1 + w_{22}x_2 + b_2$$
$$z_3 = w_{13}x_1 + w_{23}x_2 + b_3$$

So instead of one output, we get a whole vector:

$$X \rightarrow [z_1, z_2, z_3]$$

These are called **logits** — separate logits for each class, one per possible outcome. Visually:

```text
LOGISTIC

X ─────→ z


SOFTMAX

             ┌→ z₁
X ───────────┼→ z₂
             └→ z₃
```

*One question, one answer* becomes *one question, many candidate answers*.

---

## 🎬 Scene 4: Turning Scores into Belief

Raw scores (logits) don't mean much on their own — they need to become **probabilities**, something between 0 and 1 that expresses confidence.

**Logistic Regression** reaches for the **Sigmoid** function:

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

Feed it `z = 2.3`, and it whispers back:

$$P(y=1) \approx 0.91$$

Sigmoid's job, in plain words: *"How probable is Class 1?"*

**Softmax Regression**, holding its vector of logits `[z1, z2, z3]`, reaches for **Softmax**:

$$P_k = \frac{e^{z_k}}{\sum_j e^{z_j}}$$

Given logits `[2.5, 1, -0.5]`, Softmax transforms them into a full probability distribution:

$$[0.844, 0.114, 0.042]$$

Softmax's role is to take that entire vector of raw scores and convert it into a probability distribution spread across *every* class — not just one.

---

## 🎬 Scene 5: The Shape of the Output

This difference is where things really feel different.

With **Logistic Regression**, you get *one* number:

$$P(y=1) = 0.8$$

And because there are only two doors, the other probability is implied — it's just the leftover:

$$P(y=0) = 1 - 0.8 = 0.2$$

So really: `[0.2, 0.8]`.

With **Softmax**, there's no "leftover math" — you get *all* the probabilities directly:

$$[0.2, 0.7, 0.1]$$

```text
Class 0 → 20%
Class 1 → 70%
Class 2 → 10%
```

And they always add up to exactly one:

$$0.2 + 0.7 + 0.1 = 1$$

This *sum-to-one* property is one of Softmax's defining fingerprints — it's not just picking a winner, it's distributing belief across the whole field of candidates.

---

## 🎬 Scene 6: How We Label the Truth

**Logistic Regression** keeps its targets simple:

```text
Student → Placed
y = 1
```

Just `0` or `1`.

**Softmax Regression** represents the truth differently — using **one-hot encoding**, where every class gets its own slot, and only the correct one lights up:

```text
Placed      → [1, 0, 0]
Not Placed  → [0, 1, 0]
Opt-out     → [0, 0, 1]
```

This representation becomes essential in the next scene — because it's what makes the loss function work so elegantly.

---

## 🎬 Scene 7: Measuring the Mistake

Every model needs a way to say *"how wrong was I?"* — that's the **loss function**.

**Logistic Regression** uses **Binary Cross-Entropy**:

$$L = -\left[y\log(p) + (1-y)\log(1-p)\right]$$

It's built exclusively for a *Class 0 vs Class 1* world.

**Softmax Regression** graduates to **Categorical Cross-Entropy**:

$$L = -\sum_{k=1}^{K} y_k \log(P_k)$$

And across an entire dataset of size *M*, it's averaged:

$$L = -\frac{1}{M}\sum_i \sum_k y_k^{(i)} \log(\hat{y}_k^{(i)})$$

---

## 🎬 Scene 8: The Beautiful Simplification

Here's a little magic trick hidden inside that formula. Suppose the true label is:

$$y = [0, 1, 0]$$

and the model predicted:

$$P = [0.2, 0.7, 0.1]$$

Plug it into the loss:

$$L = -\left[0\log(0.2) + 1\log(0.7) + 0\log(0.1)\right]$$

Because the one-hot label zeroes out everything except the correct class, the formula collapses:

$$\boxed{L = -\log(0.7)}$$

*That's the whole point.* The model only ever cares about **how confident it was in the correct answer**. Everything else disappears from the equation — a quiet elegance baked right into the math.

---

## 🎬 Scene 9: Learning From Mistakes

Both models learn the same way in spirit: **gradient descent**.

**Logistic Regression** computes gradients for its handful of parameters:

$$\frac{\partial L}{\partial w_1}, \frac{\partial L}{\partial w_2}, \frac{\partial L}{\partial b}$$

then nudges them:

$$w_{new} = w_{old} - \alpha \frac{\partial L}{\partial w}$$

**Softmax Regression** does the exact same *dance*, just with more dancers on stage. For 3 classes and 2 features, that's:

$$3 \times (2 + 1) = 9 \text{ parameters}$$

All of them get gradients calculated and updated **jointly** — a coordinated optimization across every class at once, rather than a single lonely weight vector.

---

## 🎬 Scene 10: Making the Final Call

**Logistic Regression** decides using a **threshold**. Suppose:

$$P(y=1) = 0.73$$

Since `0.73 > 0.5`:

$$\hat{y} = 1$$

**Softmax Regression** decides using **argmax** — simply picking whichever class has the highest probability. Suppose:

$$P = [0.15, 0.72, 0.13]$$

$$\arg\max(P) = 1 \implies \hat{y} = 1$$

```text
Logistic:
Probability → Threshold → Class

Softmax:
Probabilities → Argmax → Class
```

*Argmax* simply means: select the class carrying the highest Softmax probability — no threshold negotiation needed, just "whoever's winning, wins."

## ✨ The Final Takeaway

Strip away the notation, and the story is simple: **Softmax Regression is Logistic Regression, grown up to handle more choices.**

- *One logit* becomes *K logits*
- *Sigmoid* becomes *Softmax*
- *One probability* becomes *K probabilities that sum to one*
- *Binary Cross-Entropy* becomes *Categorical Cross-Entropy*
- *Threshold* becomes *Argmax*

Every stage rhymes with its binary counterpart — nothing about the architecture is foreign. So the next time multiclass classification feels intimidating, remember:

> **You already know this algorithm. You just met it when it only had two doors to choose from.**
